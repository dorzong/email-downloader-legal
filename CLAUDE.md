# email-downloader-legal

Repositorio **público** en GitHub (`dorzong/email-downloader-legal`) con las dos páginas que Google
exige para publicar la app OAuth `email-downloader` (proyecto de Google Cloud `gmail-extension-509905`):

- `index.html` → https://dorzong.github.io/email-downloader-legal/ (Application home page)
- `privacidad.html` → https://dorzong.github.io/email-downloader-legal/privacidad.html (privacy policy)

Se publican con GitHub Pages desde `main`. El programa que descarga está en
`/Users/user1/dorchuapps/email-downloader/`. **Acá nunca van correos ni datos personales.**
